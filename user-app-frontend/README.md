# React User Management App

A React application that fetches and displays users from DummyJSON API.

## Features

- Display user list
- Search users
- Refresh user data
- Add static local user
- Delete users locally
- Responsive UI using Chakra UI

## Tech Stack

- React
- Axios
- Chakra UI

# Prerequisites

- Node.js >= 24.16.0
- npm =  11.13.0

## Installation

```bash
unzip file 

cd project-name

npm install
```

## Run Application

```bash
npm run dev
```

## API Used

https://dummyjson.com/users
